Decision Points
  • ▼ ai-generation.yml (Manual Queue Only)
    • ▼ Manual Queue Trigger
    • ▼ 📋 Queue Parameters
      • • brdFile (default: brd/*.doc)
      • • promptOverride (skip BRD, use custom prompt)
      • • testScope (@regression, Module, All tests, or (skip))
    • ▼ STAGE 1: AI Generation
      • ▼ 1. Install Node.js 18.x
      • ▼ 2. Install npm + Claude Code CLI
      • ▼ 3. Resolve BRD Input
      • ▼ ⚙️ ADO_Full_Pipeline Skill
        • ▼ PHASE 0: Setup & Entry Point
          • ▼ Setup_Workspace Skill
            • ✓ stories/
            • ✓ test_cases/
            • ✓ src/pages/ · tests/generated/
          • ▼ Entry Point Detection (3-tier)
        • ▼ PHASE 1: BRD → User Stories
          • Apply INVEST principle
          • 📄 Output: stories/<FeatureName>_UserStories.md
        • ▼ PHASE 1.5: ADO_USs_To_TCs Skill
          • Create User Story work items in ADO
          • 📄 Output: stories/<FeatureName>_ADO_IDs.json
        • ▼ PHASE 2: User Stories → Test Cases
          • Convert AC → manual test cases
          • 📄 Output: test_cases/<FeatureName>_TestCases.md
        • ▼ PHASE 2.5: TCs_To_ADO Skill
          • Create Test Plan + Static Suite
          • 📄 Output: test_cases/<FeatureName>_ADO_TCs.json
          • Link TCs to parent US via TestedBy
        • ▼ PHASE 3: Test Cases → Playwright
          • Generate Page Object Model + Specs
          • 📄 src/locators/*.ts
          • 📄 src/pages/*.ts
          • 📄 tests/generated/*/*.spec.ts
        • ▼ PHASE 3.5: Polish_Generated_Code Skill
          • Task 1: Remove stray backslash escapes
          • Task 2: Scaffold missing page methods
          • Task 3: Extract inline locators
          • Task 4: Re-arrange page methods
        • ▼ PHASE 4: Git Branch & Commit
          • Create: feature/<FeatureName>
          • Stage Playwright artifacts only
          • Push to remote
      • ▼ Publish Stage 1 Artifacts
        • 📦 generated-stories
        • 📦 generated-test-cases
        • 📦 generated-playwright-scripts
    • ▼ Stage 2 Condition Check
      • ✅ If Stage 1 succeeded AND testScope ≠ (skip)
      • ❌ If testScope = (skip) → END
    • ▼ STAGE 2: Execute & Fix Tests
      • ▼ Resolve Test Scope
        • @regression/@smoke → grep filter
        • Module name → tests/generated/Module/
        • All tests → tests/generated/
      • ▼ Execute_And_Fix_Tests Skill
        • 1. Run Tests (npx playwright test)
        • 2. Parse Failures (extract TC ID, error)
        • 3. Live Inspect (Playwright MCP browser)
        • 4. Classify & Plan (9 categories)
        • ▼ 5. Apply Fixes (by category)
          • LOCATOR → Fix in src/locators/
          • LOCATOR-STRICT → Narrow selector
          • TEXT → Update assertion
          • ASSERTION → Fix logic
          • METHOD-MISSING → Add to POM
          • NAVIGATION → Fix URL
          • TIMING → Add waitForLoadState
          • AUTH → Run auth:setup
          • COMPILE → Fix TypeScript errors
      • ▼ Re-run Loop (up to 2 iterations)
        • ✅ All pass → Stop, report success
        • 🔄 Still failing → Loop back
        • ⛔ After 2 attempts → Mark BLOCKED
      • ▼ Publish Test Results
        • 📊 JUnit test results
        • 📊 Playwright HTML report
        • 📋 Test execution summary
